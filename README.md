 🔎 Lost Item Finder System

📌 Overview
The Lost Item Finder System is an IoT-based solution that helps users locate misplaced or lost items using a microcontroller and wireless communication.

This system alerts the user when the item goes out of range and helps in tracking it easily.

🎯 Objectives
- To design a smart system for finding lost items
- To provide real-time alerts using buzzer/LED
- To improve safety of personal belongings
- To develop a low-cost and user-friendly solution

 🛠️ Components Used
- ESP32 / Arduino Uno
- Bluetooth / WiFi Module (ESP32 has built-in)
- Buzzer
- LED
- Push Button
- Battery
- Mobile phone (for monitoring)


⚙️ Working Principle
1. The device is attached to an item (like keys or bag)
2. It connects to a mobile phone using Bluetooth/WiFi
3. If the item moves out of range:
   - Buzzer turns ON
   - LED starts blinking
4. User can track or locate the item using signal strength or alert system


🔌 Circuit Connections (Basic)
- LED → Digital Pin (with resistor)
- Buzzer → Digital Pin
- Button → Input Pin
- ESP32 → Power (3.3V)


💻 Code Features
- Bluetooth/WiFi connectivity
- Distance/range detection
- Alert system using buzzer & LED
- Simple and efficient logic


🚀 Applications
- Finding lost keys, wallets, bags
- Personal item tracking
- Office and home use
- Travel safety


 🔮 Future Enhancements
- GPS tracking integration
- Mobile App development
- Cloud storage for tracking history
- Voice alert system
